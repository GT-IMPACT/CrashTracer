# Реализация после ручного прохода и ревью

Код охватывает локальные подсистемы концепта. Выполнен [серверный проход](13-server-verification.md).
Проверен IMPACT dev-42: после отдельного исправления GregTech — 17 PASS,
три кейса не выполнены. Исходный FAIL после servercrash закрыт повтором на
исправленном GT, история сохранена. Результаты и границы:
[ручной проход](16-impact-modpack-test-cases.md), [ревью кандидата](17-release-review.md).

| Подсистема | Реализация |
| --- | --- |
| Bootstrap | Java, session.json, файловая блокировка, резерв памяти, сохранение прежнего handler |
| Capture | CrashReport, FML LoadController, Mixin PREPARE/APPLY errors, uncaught exceptions |
| BetterCrashes | Опциональный late-хук CrashUtils.outputReport, условное подключение по mod ID |
| Исключения | Ограниченный граф cause/suppressed с циклами, root exception, связь повторных уведомлений |
| Контекст | Моды/JAR, версии, coremods, tweakers, трансформеры, FML, измерения, heap, потоки |
| Runtime | Ограниченная история, JSONL, WARN/ERROR/FATAL, резерв критичных событий |
| Mixin | Реестр/config/target/priority/источник, ошибки, явные статусы достоверности |
| ASM | Обёртки с preInit, хеши, ошибки, MixinMerged, экспорт; специальные трансформеры остаются без обёртки |
| Анализ | Атрибуция по ZIP entries, прямым Mixin failures, FML/ASM errors, объяснение уверенности |
| Эвристики | OOM, отсутствующие классы, VerifyError, deadlock, возможные взаимодействия трансформеров |
| Маппинги | Локальные methods.csv/fields.csv, сохранение исходных имён, отдельный результат |
| Нормализация | SHA-256 fingerprint без строк исходника, индекс групп |
| Отчёты | Версионированный JSON, TXT, atomic replace, аварийный fallback, раннее восстановление |
| Хранение | Config, байтовые квоты, retention, блокировки, защита от обхода внешних ссылок |
| Зависания | Heartbeats, watchdog, ThreadMXBean deadlocks, cooldown; ID/состояние владельца блокировки |
| Native | Импорт доступных hs_err прошлого процесса с учётом уже импортированных файлов |
| CLI | Отдельный runnable JAR с Kotlin/Gson, без игрового runtime, повторный анализ |

Ограничения конкретных адаптеров, defaults и команды перечислены в корневом README.
MCP CSV пользователь размещает локально; готовый набор маппингов не включён в JAR.
Полный bytecode dump и обёртки выключены по умолчанию.

Нельзя автоматически доказать виновность по наличию мода/миксина в стектрейсе,
восстановить не записанную историю или гарантировать отчёт после завершения JVM.
Эти границы сохраняются независимо от результатов тестирования.
