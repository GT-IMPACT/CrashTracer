## GregTech после servercrash

Установленный GT берёт TICK_LOCK на ServerTickEvent.START и освобождает на END.
Тестовое исключение после START пропускает END. Новый сервер в той же JVM ждёт
lock прежнего завершившегося потока. Это подтверждено bytecode и jstack IMP-06.
Локальная правка поведения GT/BetterCrashes не входит в диагностический мод;
универсально безопасного автоматического unlock нет. Решение для пользователя —
полный перезапуск процесса после такого server crash. В кандидате добавлен
диагностический вывод для завершившегося владельца, а не игровой recovery patch.
