# Ранний запуск и обнаружение сбоев

## Bootstrap

Подготовить каталог диагностики и `session.json` до обычной инициализации модпака. Проверить доступные механизмы UniMixins; при необходимости использовать Coremod/LaunchWrapper. Само наличие UniMixins не гарантирует обработку всех ошибок до Forge.

Ранняя часть должна иметь минимум зависимостей и защиту от повторной инициализации и рекурсивных ошибок. Она не должна случайно инициировать загрузку игровых классов или отключённых интеграций.

## Источники инцидентов

Сначала использовать существующие точки формирования отчётов BetterCrashes и UniMixins. При отсутствии BetterCrashes подключать стандартный путь Minecraft/Forge. Собственные дополнительные перехватчики вводить по мере выявления непокрытых случаев.

| Кандидат точки интеграции | Нужные сведения |
| --- | --- |
| Minecraft | Инициализация, основной цикл, обработка падения |
| `FMLClientHandler` | Этапы загрузки клиента |
| `Loader` / `LoadController` | Фазы FML и ошибки загрузки модов |
| `CrashReport` | Исключение и момент создания штатного отчёта |
| Обработчики BetterCrashes | Контекст сбоя в существующем механизме |
| `LaunchClassLoader` | Ошибки загрузки и трансформации классов |
| Mixin processor | Ошибки применения миксинов |

Точные методы и дескрипторы ещё не выбраны. LaunchClassLoader и Mixin processor — экспериментальные адаптеры после MVP; они особенно чувствительны к порядку загрузки.

`UncaughtExceptionHandler` может быть дополнительным источником. При его подключении сохранять и вызывать предыдущий обработчик. Он не покрывает исключения, уже перехваченные игрой или BetterCrashes.

## Обработка

- Сохранять исходный `Throwable`, цепочки `cause`, `suppressed` и стектрейсы.
- Связывать несколько уведомлений об одном сбое, избегая повторной генерации отчёта.
- Не объединять отдельные последующие краши после восстановления BetterCrashes.
- Сначала записывать минимальные данные, затем выполнять доступное обогащение.
- При ошибке трейсера сохранять штатную обработку игры и предыдущие обработчики.

Не перехватывать каждый метод Minecraft: нужны несколько проверенных точек с понятным покрытием.
